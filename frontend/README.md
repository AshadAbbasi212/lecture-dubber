# Frontend

Next.js (App Router, TypeScript, Tailwind) goes here. The agent creates it in
Phase 6 with `npx create-next-app@latest`. See `docs/REQUIREMENTS.md` for the
pages needed and `docs/ARCHITECTURE.md` for the API.

Reminders:
- Urdu content needs `dir="rtl"` and an Urdu-capable font (e.g. Noto Nastaliq Urdu).
- Never load large videos into memory; stream and use chunked uploads.
